# recursos-daw

Recursos de trabajo del **Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW)** del IES Río Arba. Aquí viven los **datasets, scripts y ficheros de consulta** que se usan en las prácticas y los ejemplos de los distintos módulos.

Este repositorio acompaña a los apuntes: mientras los apuntes explican, aquí están los ficheros con los que trabajar.

## Cómo está organizado

Todo se ordena por **módulo** y, dentro de cada módulo, por **unidad**:

```
recursos-daw/
└── <módulo>/
    └── <unidad>/
        └── (ficheros: datasets, guiones, etc.)
```

Cada carpeta de unidad incluye, cuando hace falta, su propio `README.md` explicando qué contiene cada fichero. Para encontrar lo que buscas, entra en la carpeta de tu módulo y luego en la de la unidad correspondiente. El repositorio va creciendo con nuevos módulos y unidades a lo largo del curso.

## Cómo usarlo

**Si trabajas en tu equipo**, clona el repositorio una vez y tendrás todos los ficheros:

```
git clone https://github.com/codigoRonin/recursos-daw.git
```

Luego, cada vez que se añadan recursos nuevos, actualiza tu copia con `git pull`.

**Si solo necesitas los ficheros de una unidad concreta**, normalmente recibirás el enlace directo a esa carpeta por Google Classroom, junto con la práctica que los usa.

## Sobre los datos

Los conjuntos de datos de este repositorio son **ficticios**, creados para las clases. Los **lugares** que aparecen (localidades, comarcas) son reales, pero las personas, empresas e instituciones, así como las lecturas, registros y contactos, son **inventados** y no corresponden a nadie real. Algunos ficheros contienen errores a propósito (valores ausentes, duplicados, formatos mezclados): detectarlos y limpiarlos forma parte de las prácticas.

Ningún fichero de este repositorio contiene datos personales reales.
