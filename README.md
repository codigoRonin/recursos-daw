# recursos-daw

Recursos de aula del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW).
Datasets, scripts y materiales de consulta, organizados por módulo y unidad.

## Estructura

recursos-daw/
└── big-data-inteligencia-artificial/
└── ud1/ Datasets de la Unidad 1


El repositorio irá creciendo con nuevos módulos y unidades a lo largo del curso.

## Uso

Clona el repositorio y trabaja sobre los ficheros desde tu entorno:

git clone https://github.com/codigoRonin/recursos-daw.git


Los datos son ficticios; los topónimos son reales. No contienen datos personales.
