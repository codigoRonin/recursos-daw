# CP2.4 · Técnicas sueltas, tablas pequeñas — ficheros de partida

- `preparar.py`: el centinela con una asignación encadenada que no funciona (tarea a); las tareas b, c y d se escriben debajo.
- `datos/parejas.csv`: seis filas, tres parejas de avistamientos repetidos (una exacta y dos con cifras distintas).
- `datos/serie_hueco.csv`: ocho días de temperatura de un punto, con tres huecos.
- `datos/avistamientos_bruto.csv`: el registro de la temporada, sucio a propósito.

Se ejecuta con `python preparar.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
