# CP2.1 · ¿Quién está detrás de estos datos? — ficheros de partida

- `publicar.py`: el script que «anonimiza» la lista de observadores; se para con un error (tarea a) y, arreglado, escribe `publicable.csv`.
- `datos/observadores.csv`: los ocho observadores de la red, con nombre, correo, teléfono, edad y localidad. Personas inventadas; correos en `example.org`.
- `datos/avistamientos_muestra.csv`: veinte avistamientos con su `observador_id` y su nota de campo.

Se ejecuta con `python publicar.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
