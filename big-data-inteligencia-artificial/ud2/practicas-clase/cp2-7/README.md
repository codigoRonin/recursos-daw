# CP2.7 · El registro que no cuadra — ficheros de partida

- `exportar.py`: exporta las bandadas de la temporada a `resultados/bandadas.csv` y las relee; no falla, pero sobra algo (tarea a).
- `DECISIONES-ajeno.md`: el registro de limpieza que escribió otro analista de la red: ocho líneas, no todas cuadran (tareas b y d).
- `datos/avistamientos_limpio.csv` y `datos/avistamientos_bruto.csv`: las dos tablas sobre las que se comprueba cada cifra.

Se ejecuta con `python exportar.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
