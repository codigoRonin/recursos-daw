# CP2.5 · Gráficos que engañan — ficheros de partida

- `figuras.py`: tres figuras hechas deprisa sobre la tabla limpia; la primera se para con un error (tarea a) y las tres engañan (tareas b, c y d). Guarda las figuras en `figuras/`.
- `describir_figura.py`: ayudante dado. Se importa (`from describir_figura import describir_barras, describir_lineas, describir_histograma`) y describe con datos lo que hay dibujado en unos ejes. No se modifica.
- `datos/avistamientos_limpio.csv`: el registro de la temporada después de todo el apartado 4 (194 filas).
- `datos/especies.json`: las diez especies con su grupo y su estatus (tarea e).

Se ejecuta con `python figuras.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
