# CP2.6 · Seguir la pista a una fila — ficheros de partida

- `calidad.py`: carga el bruto y el limpio y se para (tarea a); las tareas b, c y d se escriben debajo.
- `datos/avistamientos_bruto.csv`: el registro de la temporada, sucio a propósito (199 filas).
- `datos/avistamientos_limpio.csv`: el mismo registro después de todo el apartado 4 (194 filas).

Se ejecuta con `python calidad.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
