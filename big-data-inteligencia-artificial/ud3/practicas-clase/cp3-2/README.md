# CP3.2 · Lo que entra y lo que sale — ficheros de partida

- `entradas.py`: una recta que se para en `fit` (tarea a), los huecos de las tareas b y c, y el preprocesado y la jornada nueva de la tarea d, ya escritos.

Se ejecuta con `python entradas.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
