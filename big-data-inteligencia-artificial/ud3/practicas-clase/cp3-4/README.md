# CP3.4 · Seguir una jornada por el árbol — ficheros de partida

- `bandadas.py`: el árbol de `hubo_bandada`, entrenado; imprime una matriz y una sensibilidad que no es la que dice (tarea a), el árbol, y deja los huecos de las tareas b, c y d.
- `datos/jornadas.csv`: las 300 jornadas de censo.
- `datos/cinco_jornadas.csv`: cinco jornadas previstas, para bajarlas a mano por el árbol.
- `datos/doce_jornadas.csv`: doce jornadas con tres preguntas contestadas con 0 y 1, para la tarea c.
- `datos/predicciones_clf.csv`: lo real y lo predicho en cuarenta jornadas de prueba, para la tarea e.

Se ejecuta con `python bandadas.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
