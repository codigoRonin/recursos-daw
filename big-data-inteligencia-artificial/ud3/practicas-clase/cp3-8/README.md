# CP3.8 · El modelo que nadie puede repetir — ficheros de partida

- `guardar_modelo.py`: el script ajeno que entrena y guarda el modelo de especies, tal como llegó (tareas a, b y c).
- `ficha-ajena.md`: la ficha de ese modelo, con diez casillas (tarea d).
- `datos/jornadas.csv`: las 300 jornadas de censo.

Se ejecuta con `python guardar_modelo.py` desde esta carpeta; escribe en `modelos/`. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
