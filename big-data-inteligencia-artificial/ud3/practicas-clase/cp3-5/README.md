# CP3.5 · Cinco pliegues y una lotería — ficheros de partida

- `ajuste.py`: una búsqueda con `GridSearchCV` ya escrita, que se para en `fit` (tarea a); los pliegues de dos candidatos; el bloque que elige un árbol mirando la prueba; y los huecos de las tareas b, c y d.
- `datos/jornadas.csv`: las 300 jornadas de censo.
- `datos/jornadas_posteriores.csv`: 80 jornadas de la primavera de 2026, posteriores a todas las demás, con su resultado.

Se ejecuta con `python ajuste.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
