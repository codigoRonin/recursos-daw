# CP3.3 · Una recta, a mano — ficheros de partida

- `recta.py`: la regresión lineal de `especies`, escrita; se para al dividir (tarea a); imprime los coeficientes y seis jornadas de prueba, y deja los huecos de las tareas b, c y d.
- `datos/jornadas.csv`: las 300 jornadas de censo.
- `datos/tres_jornadas.csv`: tres jornadas previstas, para predecirlas a mano.
- `datos/predicciones_reg.csv`: lo real y lo predicho en veinte jornadas de prueba, para la tarea e.

Se ejecuta con `python recta.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
