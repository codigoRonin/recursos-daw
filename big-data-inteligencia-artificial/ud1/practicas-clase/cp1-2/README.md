# CP1.2 · Fichas y recuentos — ficheros de partida

- `recuentos.py`: los mismos doce avistamientos del CP1.1 y dos funciones; se para con un error (tarea a) y le faltan las dos funciones de la tarea (b).
- `fichas.py`: la dataclass `Punto` completa y la clase `Avistamiento` a medias (tarea c), una función con comentario y docstring mal puestos (tarea d) y un bloque de pruebas al final que no se cambia.

Se ejecutan con `python recuentos.py` y `python fichas.py` desde esta carpeta. Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD1).
