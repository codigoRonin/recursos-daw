# CP3.7 · La matriz de permisos como dato — ficheros de partida

- `permisos.php`: la matriz página → perfiles y las funciones `puede()` y `respuesta()`.
- `casos.php`: imprime, para cada página y cada perfil, el código de estado que respondería el servidor (`php casos.php`). No se modifica.

Todo se ejecuta en el terminal; en esta práctica no hay servidor ni sesión: se decide, no se sirve.

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
