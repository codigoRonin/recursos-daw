# CP3.5 · El coste del hash — ficheros de partida

- `entrada-terminal.php`: comprueba una cuenta y su contraseña desde el terminal (`php entrada-terminal.php cuenta contraseña`). Rechaza a todo el mundo.
- `coste.php`: mide cuánto tarda `password_hash` con cuatro costes distintos (`php coste.php`).
- `datos/cuentas.json`: las ocho cuentas de la asociación, solo con hashes; las contraseñas de aula, en `datos/README.md`.

Todo se ejecuta en el terminal; en esta práctica no hay servidor.

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
