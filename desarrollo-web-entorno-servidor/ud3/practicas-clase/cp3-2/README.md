# CP3.2 · Desde tu última visita — ficheros de partida

- `novedades.php`: cuenta los anuncios publicados después de tu última visita, con una cookie que guarda la fecha del anuncio más reciente visto. Se sirve con `php -S localhost:8000` desde esta carpeta y se prueba con `curl -i` y un tarro de cookies.
- `datos/anuncios.php`: los ocho anuncios del tablón (devuelve el array).

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
