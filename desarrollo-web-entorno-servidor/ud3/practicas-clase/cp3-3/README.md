# CP3.3 · La solicitud de parcela en tres pantallas — ficheros de partida

- `paso1.php`, `paso2.php` y `paso3.php`: las tres pantallas de la solicitud; el estado viaja de una a otra por la sesión. Se sirven con `php -S localhost:8000` desde esta carpeta y se prueban con `curl` y un tarro de cookies.
- `datos/parcelas.php`: las ocho parcelas de la asociación (devuelve el array).

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD3).
