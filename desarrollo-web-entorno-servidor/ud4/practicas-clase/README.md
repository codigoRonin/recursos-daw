# Cuaderno de prácticas · UD4 — ficheros de partida

Ficheros de partida de las prácticas de clase de la UD4 del módulo 0613 (no evaluables). Los enunciados están en la página «Cuaderno de prácticas» de los apuntes del módulo; aquí solo viven los ficheros con los que se trabaja. Una carpeta por práctica, cada una con su `README.md`.

El `plantillas.php` de cada carpeta es el fichero con el que termina el apartado 4 de la unidad, tal cual.

Las soluciones no están aquí: se corrigen en clase y después se publican en el Classroom del módulo.
