# CP4.9 · La misma página, mal traducida — ficheros de partida

- `ver.php`: pinta la página del mercadillo en el terminal (`php ver.php`, con paradas; `php ver.php vacio`, sin ninguna). No se sirve.
- `plantillas/layout.php`, `plantillas/mercadillo.php` y `plantillas/parciales/parada.php`: la página original, con las plantillas de la unidad. Funciona y no tiene fallos.
- `plantillas.php`: el fichero del apartado 4 de la unidad, tal cual.
- `datos/mercadillo.php`: el día, las tres paradas y la referencia de la parada del mes.
- `leer/blade/` y `leer/twig/`: la misma página pasada a Blade y a Twig, tres ficheros en cada carpeta. **Son para leer: no se ejecutan ni hay que instalar nada.** Cada traducción tiene tres fallos.

Esta práctica se hace con papel y terminal: no hay servidor.

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD4).
