# CP2.8 · El tablón como plantilla — ficheros de partida

- `tablon-parcelas.php`: la plantilla del tablón, con sintaxis alternativa. Se sirve con `php -S localhost:8000` desde esta carpeta. Pásale `php -l` primero.
- `parciales/cabecera-huertos.php` y `parciales/pie-huertos.php`: los parciales.
- `datos/parcelas.php`: las 8 parcelas.

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
