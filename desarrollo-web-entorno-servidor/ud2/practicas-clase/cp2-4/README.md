# CP2.4 · Tramos y etiquetas — fichero de partida

- `tramos.php`: una cadena `if`/`elseif`/`else` para la cuota y otra para el tipo de riego. Se ejecuta con `php tramos.php` cambiando los valores de cabecera.

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
