# Cuaderno de prácticas · UD2 — ficheros de partida

Ficheros de partida de las prácticas de clase de la UD2 del módulo 0613 (no evaluables). Las soluciones no están aquí: se corrigen en clase y después se publican en el Classroom del módulo.
