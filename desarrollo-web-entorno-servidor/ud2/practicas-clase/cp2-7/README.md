# CP2.7 · La parcela como tipo compuesto — ficheros de partida

- `parcela.php`: la clase `Parcela` con dos métodos y el recorrido del huerto. Se ejecuta con `php parcela.php` desde esta carpeta. Pásale `php -l` primero… y no te fíes solo de él.
- `datos/parcelas.php`: las 8 parcelas (devuelve el array; se carga con `require`).

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
