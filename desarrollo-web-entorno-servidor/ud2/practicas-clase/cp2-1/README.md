# CP2.1 · Dos ficheros, dos caminos — ficheros de partida

- `tablon.php`: PHP puro, se ejecuta en el terminal con `php tablon.php`. Pásale `php -l` antes.
- `cartel.php`: PHP embebido en HTML, se sirve con `php -S localhost:8000` y se pide con el navegador.

Enunciado en el cuaderno de prácticas del módulo (página «Cuaderno de prácticas», sección UD2).
